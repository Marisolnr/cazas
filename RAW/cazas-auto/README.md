# RAW/cazas-auto — informes completos de las cazas automáticas

Un archivo por sesión: `YYYY-MM-DD-<sesión>-<modo>-<nodo>.md` (ej. `2026-09-08-es-A-huella.md`,
`2026-09-09-br-B-veterinaria-grandes-animales.md`).

Mismo formato de salida de `/cazar` (shortlist con `cohorte 7+ / activos`, links de Ads Library
filtrados por país, snapshots más duplicados, veredicto provisorio, par fuente→destino), más una
sección obligatoria **«Cobertura»**: keywords corridas por mercado, resultados por keyword, si se miró
`ALL`, y qué trampas nuevas aparecieron. Es lo que permite que la sesión siguiente no repita.

Las filas resumen van a `cazas/bandeja.md`; el nodo se actualiza en `cazas/cola.md`. Este archivo es
la evidencia. Cuando el dueño decide `Idea`, la página de producto se escribe desde acá (§7.4).

Como todo RAW: Claude lo lee, no lo reescribe.
